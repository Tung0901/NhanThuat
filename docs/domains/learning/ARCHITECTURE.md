# Learning Domain Architecture

**Domain Area:** NT-DA-0018  
**Slug:** learning  
**Status:** frozen  
**Review Owner:** Chief Architect (Autonomous Program 3 Completion)  

## 1. Domain Purpose
The Learning domain defines the organizational capability of converting operational telemetry, error feedback, and post-mortem insights into systemic capability updates.

## 2. Core Distinctions
- **Learning vs Training:** Training imparts static skills; Learning updates organizational mental models based on reality.
- **Learning vs Blame:** Blame seeks personal culpability; Learning identifies process flaws.
