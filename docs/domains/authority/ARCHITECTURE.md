# Authority Domain Architecture

**Domain Area:** NT-DA-0013  
**Slug:** authority  
**Status:** frozen

## 1. Domain Purpose
The Authority domain defines the formal assignment of decision rights, governance boundaries, and organizational power distribution.

## 2. Core Distinctions
- **Authority vs Power:** Authority is formal right (`NT-DA-0013`); Power is actual leverage (`NT-DA-0008`).
- **Authority vs Leadership:** Authority mandates; Leadership inspires (`NT-DA-0004`).
