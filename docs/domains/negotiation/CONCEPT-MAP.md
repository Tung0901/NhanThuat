# Negotiation Concept Map

**Domain Area:** NT-DA-0012  
**Slug:** negotiation  
**Status:** frozen

## 1. Domain Overview

**Scope:** The structured process of interest discovery, value expansion, resource allocation, and executable agreement design between autonomous parties.  
**Out of Scope:** Positional haggle (Bargaining alone), force/intimidation (Coercion), hidden manipulation, sales pitch (Selling), third-party intervention (Mediation), and simple compromise splitting.

## 2. Core Distinctions Matrix

| Concept | Versus | Concept | Rationale |
| --- | --- | --- | --- |
| **Negotiation** | vs | **Persuasion** | Persuasion changes mindsets; Negotiation trades binding commitments. |
| **Negotiation** | vs | **Influence** | Influence alters perceived priorities; Negotiation formalizes agreed terms. |
| **Negotiation** | vs | **Authority** | Authority imposes decisions downward; Negotiation agrees options multilaterally. |
| **Negotiation** | vs | **Manipulation** | Manipulation hides true intent; Negotiation relies on transparent interest alignment. |
| **Negotiation** | vs | **Conflict** | Conflict is the state of tension; Negotiation is the resolution process. |
| **Negotiation** | vs | **Mediation** | Mediation requires an external facilitator; Negotiation is direct party-to-party. |
| **Negotiation** | vs | **Compromise** | Compromise splits losses; Integrative Negotiation expands total value created. |
| **Negotiation** | vs | **Selling** | Selling demonstrates value fit; Negotiation defines contract risks and prices. |

## 3. Concept Clusters

### 3.1 Interest Discovery & Value Creation
- **Definitions:** Separating rigid demand positions from underlying needs to create integrative value.
- **Core Concepts:** Interest-position decoupling, value expansion, Pareto-efficiency.
- **Knowledge Units:** NT-LAW-0057, NT-LAW-0058, NT-PRINCIPLE-0087, NT-PRINCIPLE-0088.

### 3.2 Objective Allocation & Agreement Stabilization
- **Definitions:** Allocating value using neutral benchmarks and building breach-resistant contracts.
- **Core Concepts:** Objective criteria, BATNA, agreement stability, structural enforcement.
- **Knowledge Units:** NT-LAW-0059, NT-PRINCIPLE-0089, NT-MODEL-0022, NT-MODEL-0023.

### 3.3 Pathological Failures & Power Asymmetry
- **Definitions:** Avoiding positional locks, zero-sum illusions, premature surrender, and unstable deals under power imbalance.
- **Core Concepts:** Positional lock, zero-sum fallacy, premature concession, contract instability.
- **Knowledge Units:** NT-ANTI-PATTERN-0036, NT-ANTI-PATTERN-0037, NT-ANTI-PATTERN-0038, NT-ANTI-PATTERN-0039.
