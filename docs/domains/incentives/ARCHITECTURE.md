# Incentives Domain Architecture

**Domain Area:** NT-DA-0009  
**Slug:** incentives  
**Status:** frozen  
**Review Owner:** Chief Architect (Autonomous Program 3 Completion)  

## 1. Domain Purpose
The Incentives domain defines the structural payoff architectures that drive human choices and organizational priority allocation. It explains how extrinsic rewards, penalties, and implicit signals shape behavior without redefining human motivation (`NT-DA-0002`).

## 2. Core Distinctions
- **Incentives vs Motivation:** Motivation (`NT-DA-0002`) is internal psychological drive; Incentives are external payoff structures.
- **Incentives vs Compensation:** Compensation is baseline financial remuneration; Incentives are variable reward loops tied to performance telemetry.
- **Incentives vs Coercion:** Coercion forces compliance via threat; Incentives align payoff choices voluntarily.
