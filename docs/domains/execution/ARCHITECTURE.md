# Execution Domain Architecture

**Domain Area:** NT-DA-0017  
**Slug:** execution  
**Status:** frozen  
**Review Owner:** Chief Architect (Autonomous Program 3 Completion)  

## 1. Domain Purpose
The Execution domain defines the operational mechanics of turning strategic choices and commitments into physical work output, maintaining cadence, and managing bottleneck throughput.

## 2. Core Distinctions
- **Execution vs Planning:** Planning designs the roadmap; Execution mobilizes energy to ship work.
- **Execution vs Effort:** Effort is energy expended; Execution is verified output delivered.
