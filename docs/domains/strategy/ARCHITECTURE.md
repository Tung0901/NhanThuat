# Strategy Domain Architecture

**Domain Area:** NT-DA-0016  
**Slug:** strategy  
**Status:** frozen  
**Review Owner:** Chief Architect (Autonomous Program 3 Completion)  

## 1. Domain Purpose
The Strategy domain defines the structured framework for choosing where to concentrate scarce resources to achieve competitive advantage.

## 2. Core Distinctions
- **Strategy vs Planning:** Strategy is choosing *what* to do and *what not* to do (`NT-DA-0016`); Planning is scheduling the execution steps (`NT-DA-0017`).
- **Strategy vs Tactics:** Strategy sets direction; Tactics execute specific maneuvers.
