# Culture Domain Architecture

**Domain Area:** NT-DA-0019  
**Slug:** culture  
**Status:** frozen  
**Review Owner:** Chief Architect (Autonomous Program 3 Completion)  

## 1. Domain Purpose
The Culture domain defines the shared norms, implicit assumptions, and behavioral patterns that govern how work is executed when no one is watching.

## 2. Core Distinctions
- **Culture vs Rules:** Rules define explicit legal constraints; Culture defines implicit social defaults.
- **Culture vs Values:** Values are stated aspirations; Culture is actual observed behavior.
