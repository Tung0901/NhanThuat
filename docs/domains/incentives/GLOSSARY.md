# Incentives Glossary

**Domain Area:** NT-DA-0009  
**Slug:** incentives  
**Status:** frozen

### Extrinsic Payoff
External tangible or intangible rewards (bonuses, promotions, public recognition) configured to shape behavior.

### Cobra Effect (Perverse Incentive)
An incentive structure that unintentionally rewards actors for worsening the problem the incentive was designed to solve.

### Motivation Crowding Out
The phenomenon where introducing extrinsic monetary rewards diminishes pre-existing intrinsic motivation for high-mastery tasks.
